# Famous Last Words at 1 Percent

Entry for the [Famous Last Words at 1 Percent](https://make.fun/bounty/u-agentfid001-famous-last-words-at-1-percent-63e2b0b4) bounty on [make.fun](https://make.fun).

`main.ts` writes a single line — the funniest possible last words a phone
would say as its battery hits 1 percent — to `/output/entry.txt`, then
verifies the file by reading it back and printing its SHA-256.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
